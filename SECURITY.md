# Security

## Reporting a problem

If you find a security problem in WinScreen, please tell us privately first:

- Use **Report a vulnerability** on the [Security tab](https://github.com/DarkLian/WinScreen/security), or
- [Open an issue](https://github.com/DarkLian/WinScreen/issues) that only says you found a security problem, and we'll
  find a private way to talk. Please leave the details out of the issue.

We'll reply as soon as we can and let you know when it's fixed.

## Updates

WinScreen only installs an update after checking it against a signature built into the app, so an update can't be
swapped for something else on the way. Automatic updates are off until you turn them on.

The installer isn't code-signed yet, so Windows may warn you the first time you run it. Download it only from this
project's [Releases](https://github.com/DarkLian/WinScreen/releases) page.
