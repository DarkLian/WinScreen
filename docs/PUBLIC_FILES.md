## Published release assets

The release workflow uploads generated files from `dist/release` as GitHub Release assets. These are public downloads, but are not committed source files:

- `WinScreen-win-Setup.exe`
- `WinScreen-VERSION-full.nupkg`
- `WinScreen-win-Portable.zip` (the portable archive generated by Velopack)
- `releases.win.json` and `releases.win.json.sig`
- Velopack release index files, if generated

Release publication requires the private signing key in a GitHub Actions repository secret. The secret and local private key are not published.
